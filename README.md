# AI-X_drone-game-ai-deeplr
Unity 환경에서 Recurrent PPO 기반 드론 게임 AI

## 프로젝트 소개

이 프로젝트는 플레이어의 움직임과 주변 장애물에 대응하는 드론 AI를 만드는 데서 시작했습니다.

드론을 학습시키면서 상대 플레이어의 행동도 중요하다는 점을 확인했습니다. 단순하게 도망가는 상대뿐 아니라, 드론의 사각지대로 이동하거나 건물 안으로 숨는 상대에게도 대응할 수 있어야 하기 때문입니다.

이를 위해 플레이어의 이동 전략도 심층강화학습으로 학습하고, 플레이어와 드론을 번갈아 개선하는 실험을 진행하고 있습니다.

## 이 블로그에서 다루는 내용

- Unity 기반 드론·플레이어 학습 환경 구성
- 에이전트의 관측 정보와 행동 설계
- PPO 기반 정책 학습과 보상 설계
- 추격, 회피, 엄폐와 재교전 실험
- 학습 결과 비교와 실패 원인 분석

현재 다루는 대상은 Unity 게임 속 AI입니다. 플레이어의 조준과 사격은 자동 전투 로직이 담당하며, 플레이어 정책은 이동과 달리기 선택을 학습합니다.

성공한 결과뿐 아니라 의도와 다르게 나타난 행동, 수정한 이유, 아직 해결하지 못한 문제도 함께 기록합니다.
