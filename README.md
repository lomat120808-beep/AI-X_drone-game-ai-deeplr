# AI-X_drone-game-ai-deeplr
Unity 환경에서 Recurrent PPO 기반 드론 게임 AI

## 프로젝트 소개

게임에서 비플레이어 캐릭터(Non-Player Character)의 행동은 환경 정보를 인식하고, 상황에 적합한 행동을 선택하여, 이를 이동이나 공격으로 실행하는 여러 시스템을 결합함으로써 구현된다. 기존 게임 AI의 행동 선택은 유한 상태 기계(Finite State Machine), 행동 트리(Behavoir Tree), 목표 지향 행동 계획(Goal-Oriented Action Planning) 등의 기법이 활용되어 왔다. FSM은 순찰, 추격, 공격 등의 상태와 전이 조건을 행동으로 구성한다. 행동 트리는 조건과 행동을 계층적으로 조직하여 상황에 따라 실행할 작업을 선택한다. GOAP는 정의된 목표와 행동 모델을 바탕으로 목표 달성에 필요한 행동의 순서를 탐색한다. 이들은 각 다른 탐지 및 이동 시스템과 결합하여 의사 결정을 이룬다.

하지만 이러한 규칙 기반 게임 AI의 행동 선택에는 몇 가지 문제점이 존재한다. 이번 프로젝트에서는 이러한 행동 선택을 개선하기 위해 Recurrent PPO 기반 딥러닝으로 게임 AI를 진행할 예정이다. Recurrent PPO 방식을 선택한 이유는 다음과 같다.

1. 복잡한 상황을 종합해서 판단할 수 있다.
규칙 기반으로 플레이어 AI를 만들면 다음처럼 조건을 정할 수 있다.

```
체력이 30% 미만이면 후퇴
적이 사거리 안에 있으면 공격
탄약이 없으면 재장전
```
하지만 실제로 후퇴해야 하는지 판단하는 것은 체력만으로 결정되지 않는다.
- 적과 떨어진 거리 및 이동 속도 차이
- 근처 지형지물 상황
- 남은 탄약과 아이템
- 적의 체력
- 보급 상황
기존 규칙 기반 플레이어 AI는 이러한 입력들의 복합적인 관계를 구현하기 어렵다. 딥러닝을 이용하면 이런 입력을 이용한 판단을 데이터에서 배울 수 있다.

2. 장기적인 결과를 반영한 판단을 학습할 수 있다.
지금 좋은 행동이 최종적으로 좋은 행동이 아닐 수도 있다. 강화학습은 누적 보상을 높이도록 학습하므로, 충분한 훈련과 적절한 보상 설계가 있다면 당장의 이득과 이후의 손해를 함께 고려하는 정책을 배울 수 있다.

3. 사람의 플레이 스타일을 데이터로 배우고, 대응할 수 있다.
규칙 기반 게임 AI는 특정 패턴에 의존하는 경향을 보인다. 그리고 숙련자가 자연스럽게 하는 행동이지만 말로 설명하기 어려운 플레이 스타일이 있는데, 딥러닝은 이러한 사람의 데이터를 학습하여 많은 상황의 조합에 대한 판단을 학습할 수 있다.
